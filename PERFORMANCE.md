# Оптимизации быстродействия

При загрузке исследования `CaseState` сохраняет минимум интенсивности и
начальные параметры контраста. Получение поперечных срезов больше не требует
повторного поиска минимума во всём объёме; параметры контраста МР также
используются повторно. Пиксели, интерполяция и преобразования координат сохранены.

Просмотр поверхности и построение расчётной сетки используют общий кэш VTK
поверхностей, по одной записи на сторону. Ключ учитывает контуры, геометрию
изображения и настройки реконструкции. Параллельные запросы не дублируют
реконструкцию; каждый потребитель получает отдельную копию VTK-данных.

Просмотрщик CFD создаёт вершины, индексы треугольников и их площади один раз
при загрузке результатов. При изменении поля, кадра или порога обновляется
цветовой источник; неизменные источники геометрии используются повторно.
Повторные перерисовки с теми же параметрами используют готовую геометрию.
SceneKit обновляет объект в существующей сцене, сохраняя камеру.
При присоединении 3D-вью к окну и смене геометрии запрашивается перерисовка,
чтобы повторное открытие кэшированной модели не оставляло пустой фон.

## Проверки

Из корня проекта:

```sh
.venv/bin/python -m unittest discover -s server/tests -v
```

Девять проверок охватывают совпадение пикселей и координатных базисов,
поверхность на синтетическом сосуде, изоляцию копий, обновление кэша после
правок, сброс кэша через workflow и одновременные запросы просмотра и построения сетки.

Полный набор серверных проверок, включая сохранение проектов и фоновые задания:

```sh
.venv/bin/python -m pytest -q tests server/tests
```

Сборка приложения:

```sh
cd CarotidSegApp
swift build
```

Три проверки Swift Testing проверяют переиспользование вершин и индексов,
обновление цветов и диапазона значений, а также площади фильтрованных областей.
С полным Xcode используется `swift test --disable-xctest`. В окружении с
Command Line Tools, где Testing.framework не включён в стандартный путь поиска:

```sh
swift test --disable-xctest --enable-swift-testing \
  -Xswiftc -F \
  -Xswiftc /Library/Developer/CommandLineTools/Library/Developer/Frameworks \
  -Xlinker -rpath \
  -Xlinker /Library/Developer/CommandLineTools/Library/Developer/Frameworks
```

## Локальные замеры

На синтетическом объёме `float32` размером 256 × 512 × 512 (256 МиБ),
для среза 160 × 160 пикселей медиана десяти вызовов всей функции
`sample_oblique_slice` составила 7,20 мс с повторным поиском минимума и
2,04 мс с сохранённым минимумом. Пиксели совпали.

Для небольшого синтетического прямого сосуда первая реконструкция поверхности
заняла 36,25 мс, повторное получение из кэша с проверкой ключа и копированием —
0,67 мс (медиана десяти вызовов).

Эти числа относятся к отдельным операциям на синтетических данных.
Время всего приложения, отрисовка на больших сетках и полный CFD-расчёт
на реальном исследовании в рамках этой доработки не измерялись.

Для применения изменений к уже запущенной сессии нужно сохранить проект,
перезапустить приложение и Python-сервер, затем открыть проект снова.
